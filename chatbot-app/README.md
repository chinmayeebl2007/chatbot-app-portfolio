# 🤖 Chinmayee AI – Personal Portfolio Assistant

An AI-powered portfolio website that allows visitors to interact with my portfolio through a conversational chatbot.

## 🚀 Features

- AI-powered portfolio assistant using Google Gemini
- Interactive chat interface
- Portfolio-focused responses
- Featured project cards
- Resume viewer
- Contact page
- Chat history
- Dark / Light mode
- Responsive design
- Knowledge-base driven answers

---

## 🛠 Tech Stack

### Frontend

- React
- TypeScript
- Vite
- CSS
- Lucide React

### Backend

- Node.js
- Express.js
- Google Gemini API

## ⚙️ Installation

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd chatbot-backend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside `chatbot-backend`.

```env
GEMINI_API_KEY=YOUR_API_KEY
```
